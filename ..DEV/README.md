# Lumynity Studios Web Developer Info

### Easy tests
| Script      | Action                                                                    |
| :---------- | :------------------------------------------------------------------------ |
| `run.bat`   | Installs dependencies if not installed, then starts local dev server      |
| `run.bat`   | Starts local dev server at `localhost:2137` if dependencies are installed |

### Test before push.
Always test any changes you've made to the website to make sure any related code didn't break.
If you find something that's broken but don't have the time or energy to fix it, add it to the TODO.

### Update on progress.
Update the TODO when you complete a task from it.

Inform others when you're about to do major changes so they can commit their code before you begin.

### Keep the (CSS) code CLEAN.
**Mesurement Uses**
- Font/text stuff: em
- Max Width, Max Height, Width, Height: px
- Border, Border Radius: px
- Padding, Gap: rem

**Order**
- System (Font etc.)
- Display, Flex, Flex Direction, Float, Templates, Algin Items, Justify Content
  - Used templates: `grid-template-columns`
- Position
- Background, Background Image, Background Origin, Background Clip, Color
- Border, Border Image, Border Radius, Box Sizing, Box Shadow
- Margins, Padding, Gap
- Max Width, Max Height, Width, Height
- Animation (Transition)

For PX to REM conversion use: https://nekocalc.com/px-to-rem-converter

If using new element types, add them to the order/mesurement lists in a fitting manner
